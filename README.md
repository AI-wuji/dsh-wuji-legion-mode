# ⚔️ 无极军团模式 · dsh-wuji-legion-mode

> DeepSeek Harness 的独立“无极军团模式”项目。

本仓库把无极军团作为一个**可选、独占、完整的 agent preset / runtime profile**：只有用户选择“无极军团模式”时，阿极、铁律、参谋部、主帅、官员、任务投影、记忆和治理工具才会启动。

## 两个项目怎么选 / Choose Your Project

无极军团拆成两个互补项目，但它们不是同一个运行层：

| 项目 | 主要职责 | 适合谁 | 是否直接成为 DSH 模式 |
|---|---|---|---|
| [`dsh-wuji-legion-global`](https://github.com/AI-wuji/dsh-wuji-legion-global) | 全局架构、研究资料、能力目录、基础集成与长期演进 | 想研究、扩展或维护无极军团整体系统的人 | 否。它不是可选聊天模式 |
| **模式版** `dsh-wuji-legion-mode` | 可选择的独占运行模式：preset、铁律、军团工具、投影和治理链 | 想在 DSH 中启用完整无极军团体验的用户 | 是。只有选择本模式才启动军团设定 |

### 你应该进入哪个仓库？

- 想了解无极军团整体设计、研究依据或底层建设：前往 [`dsh-wuji-legion-global`](https://github.com/AI-wuji/dsh-wuji-legion-global)。
- 想安装并使用“无极军团模式”：留在当前仓库。
- 想使用其他 DSH 模式：不需要安装本项目；其他模式不加载这里的 persona、铁律、工具和治理链。

> 全局版负责“整体系统如何存在”，本项目负责“用户选择无极军团后如何运行”。看到全局版想体验模式，或看到模式版想研究完整体系，都可以通过上面的链接跳转。

## 模式边界

选择其他 DSH 模式时：

- 不加载无极军团 persona、铁律和任务契约；
- 不注册 `wuji_*` 工具、投影和军团专用路由；
- 不自动继承无极军团的记忆、模型路由或治理策略；
- 其他模式可以作为裸机或按自己的需求安装插件。

选择无极军团模式时：

- 加载阿极用户接口与完整铁律；
- 启用参谋部任务规划、依赖调度和执行回执；
- 启用主帅选型、官员建议、记忆、进化和状态投影；
- 只加载已声明兼容且没有核心冲突的共享能力；模式专属插件默认隔离。

> “已安装”不等于“当前模式已加载”。插件的安装目录可以复用，但运行时注册必须经过当前模式的兼容性筛选。

## 当前实现

- `preset/`：无极军团模式的 agent preset 设计；
- `packages/wuji-host/`：模式专用 Host 插件与投影/工具；
- `skills/`：模式能力注册表；
- `scripts/`：模式 profile 安装脚本；
- `docs/`：模型路由、状态和运行边界说明。

## 状态

私有开发版本。模式隔离仍需在真实 DSH Desktop profile 切换中验证；在隔离验证完成前，不宣称已实现运行时热切换。
