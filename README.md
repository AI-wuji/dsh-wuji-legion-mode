# ⚔️ 无极军团模式 · dsh-wuji-legion-mode

> DeepSeek Harness 的独立“无极军团模式”项目。

本仓库把无极军团作为一个**可选、独占、完整的 agent preset / runtime profile**：只有用户选择“无极军团模式”时，阿极、铁律、参谋部、主帅、官员、任务投影、记忆和治理工具才会启动。

## 它是什么 / What This Is

这是 DeepSeek Harness 的**无极军团模式**：一个可选择、独占、完整的多智能体运行模式。它不是普通的聊天人格，也不是默认全局插件；用户只有主动选择该模式，才会进入无极军团的工作体系。

模式的核心特色是把阿极、铁律、参谋部、主帅、独立官员、任务投影、记忆和治理工具作为一套完整运行契约统一启用。它面向希望把复杂目标交给一支有组织、可调度、可审查、能持续交付的智能体军团来完成的用户。

## 模式特色 / Mode Features

- **主动选择才启动**：不替换极简模式，也不把军团设定注入其他模式。
- **完整规则一起生效**：阿极 persona、铁律、任务契约、调度链、状态投影和治理约束属于同一个模式边界。
- **与其他模式隔离**：离开本模式后，不加载 `wuji_*` 工具、军团记忆、专用路由或治理规则。
- **插件按模式筛选**：已安装不等于已加载；只有基础能力或明确兼容且无冲突的插件，才可进入本模式。
- **复杂任务优先**：适合多步骤执行、长期目标、跨能力协作、需要验证和回执的工作。

## 另一个项目：全局版 / The Global Project

无极军团还有一个负责整体建设的全局项目：[`dsh-wuji-legion-global`](https://github.com/AI-wuji/dsh-wuji-legion-global)。全局版保存无极军团的总体理念、系统架构、研究依据、能力目录、基础集成和长期演进记录，但它本身不是一个需要用户选择的聊天模式。

- 想直接使用无极军团模式：留在当前仓库。
- 想了解整体设计、研究依据或参与底层建设：前往 [`dsh-wuji-legion-global`](https://github.com/AI-wuji/dsh-wuji-legion-global)。
- 想使用其他 DSH 模式：不需要安装本项目；其他模式不会加载这里的 persona、铁律、工具和治理链。

> 全局版负责“无极军团整体如何存在”，本项目负责“用户选择无极军团后如何运行”。

## 模式边界

选择其他 DSH 模式时：

- 不加载无极军团 persona、铁律和任务契约；
- 不注册 `wuji_*` 工具、投影和军团专用路由；
- 不自动继承无极军团的记忆、模型路由或治理策略；
- 其他模式可以作为裸机或按自己的需求安装插件。

选择无极军团模式时：

- 加载阿极用户接口与完整铁律；
- 启用参谋部任务规划、依赖调度和执行回执；
- 启用主帅选型、官员建议、记忆、进化和状态投影；
- 只加载已声明兼容且没有核心冲突的共享能力；模式专属插件默认隔离。

> “已安装”不等于“当前模式已加载”。插件的安装目录可以复用，但运行时注册必须经过当前模式的兼容性筛选。

## 当前实现

- `preset/`：无极军团模式的 agent preset 设计；
- `packages/wuji-host/`：模式专用 Host 插件与投影/工具；
- `skills/`：模式能力注册表；
- `scripts/`：模式 profile 安装脚本；
- `docs/`：模型路由、状态和运行边界说明。

## 状态

私有开发版本。模式隔离仍需在真实 DSH Desktop profile 切换中验证；在隔离验证完成前，不宣称已实现运行时热切换。
