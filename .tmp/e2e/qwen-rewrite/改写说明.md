# 改写说明：双重曝光元指令（z-image/SDXL 类 → qwen-image 2.1）

## 一、判定结论

原稿是给 z-image / SDXL 类模型写的，其格式归属属于**标签类模型习惯**（逗号分隔的关键词堆、画质咒语、独立 Negative Prompt 字段）。本次不支持 SDXL/Pony/SD1.5 的 booru 标签格式，因此这些格式不能作为语法模板保留；其中承载的**内容、题材、构图、风格和意图线索**被完整提取并按 qwen-image 2.1 语法重写。目标模型语法锁定优先于用户参考格式。

## 二、被拒绝的非目标模型格式清单

| # | 原稿写法 | 归属模型 | 拒绝依据 | 证据等级 |
|---|---|---|---|---|
| 1 | 末尾独立 `Negative Prompt: ` 前缀字段 | SDXL / 早期 SD 标签类 | qwen-image 2.1 无独立 negative 槽位；CFG=1（引导蒸馏）时负向无效，仅 `true_cfg_scale > 1` 才可能起作用 | `[官方]` |
| 2 | 画质词 `masterpiece, best quality, 8k, stunning visual impact` | SDXL / Civitai 标签习惯 | 参数与 prompt 分离是硬规则；把画质档位写进散文不能保证参数生效，只干扰语义。分辨率/质量档位走接口字段 | `[官方]` |
| 3 | `[摄影/插画风格] + [主体轮廓] + …` 方括号加号拼接公式 | SD1.5/SDXL 权重语法残留 | 方括号在标签类模型中表示权重调整，在自然语言编码器里只是无意义噪声；且"严格按顺序拼串"是标签模型的组装习惯，不是自然语言散文结构 | 推断（语法归属）+ `[官方]`（自然语言散文输入） |
| 4 | `"针对 z-image 等模型"` 的画质词章节归属 | z-image | 文件头、模型声明、字段契约不得把非目标模型当作适配目标；仅作内部冲突记录 | 本域规则（输出规范） |
| 5 | 关键词库以逗号列表为最终输出形态 | SDXL | 逗号标签堆是 SDXL 特征；qwen 吃连贯散文。保留词库作为**素材库**，但要求组装成通顺句子 | `[官方]` |
| 6 | 无条件生成负面词的"修复关键"章节 | SDXL 工作流 | 与 #1 同源；不改写会导致下游把无效文本塞进提示词 | `[官方]` |

## 三、每处改动的依据与证据等级

| 改动 | 内容 | 依据 | 证据等级 |
|---|---|---|---|
| A | 新增「第 0 步：模式确认」，把 Prompt Extend 开关设为开工前置分水岭 | 开=模型只吃骨架、文字被改写；关=逐元素逐字锁定。元指令必须先问要不要改写，再决定后续所有细节写法 | `[官方]` |
| B | 构建公式从"方括号加号拼接"改为"按序写成连贯散文，允许短句分段" | qwen-image 2.1 是自然语言文本编码器，输入形态是散文；分段可用但段内必须通顺 | `[官方]` |
| C | 删除全部画质咒语（masterpiece / best quality / 8k / stunning visual impact / seamless blending 中的画质用法），保留 `seamless blending, ethereal atmosphere` 这类**风格与氛围描述** | 参数分离硬规则；风格氛围属于内容描述，不属于画质档位 | `[官方]` |
| D | 负面提示词从"必须输出 Negative Prompt 字段"改为"默认不输出 + 正面可见行为约束"，附 `true_cfg_scale > 1` 的条件例外 | qwen 负向生效条件：CFG≤1 无效，需 true_cfg_scale > 1。原稿的强制规则在 qwen 上产出无效文本 | `[官方]`（CFG/负向生效条件） |
| E | 新增「跨模型铁律」章：参数分离、长度由信息密度决定、参考图派活、抽象概念翻译、一次只改一层、Wan/Qwen VAE 不可混用 | 本域跨模型铁律；Wan 与 Qwen-Image 不是同一模型族 | `[官方]`（VAE 红线）+ 本域规则（铁律条目） |
| F | 新增参考图派活条款（第 N 张图按上传顺序、每图唯一职责、不重描五官） | qwen 分支支持 1–10 张参考图；角色一致性靠指向参考图 | `[官方]` |
| G | 示例重写：原示例是标签串 + 画质词 + Negative Prompt 三段拼贴；新示例是连贯散文，无画质咒语、无 Negative 字段，排斥项改为句内正向约束 | 同 B/C/D | `[官方]` |
| H | 编辑顺序说明采用 qwen 与视频域一致的「先保持、后变化」 | qwen 分支与 GPT image 2.5 的 Change→Preserve 顺序**相反**，两套规则不得互相污染 | 本域规则 |
| I | 移除示例中与内部场景冲突的元素 | 原稿「中秋」示例把 `a full moon` 放进剪影内部场景，却又把它列为必须排除的负面词，自相矛盾。新示例只保留剪影内部有月亮、背景无月亮的正确关系 | 逻辑一致性（推断） |

## 四、保留原稿的部分及依据

| 保留项 | 依据 |
|---|---|
| 双重曝光方法论（主体剪影 + 内部填充场景，人物侧影/背影为主体） | 这是**题材与技法知识**，与模型无关；模型语法换代不改题材逻辑 |
| 七段构建顺序（风格→轮廓→技法→场景→透视→色彩→背景→约束） | 顺序本身是创作方法，非模型语法；仅把"拼接方式"从标签串改为散文。保留依据：改写只解决格式冲突，不擅自改动原稿已确定的方法论 |
| 全部关键词库内容（风格词、轮廓词、融合词、场景词、透视词、背景策略词、内外关系约束词） | 提取为素材库继续使用，只是不再以逗号标签堆为输出形态 |
| 色彩定调规则（中秋→极淡暖银、樱花→极淡粉等） | 题材到色调的映射属于内容层，不涉及语法；且"饱和度低于 3%"这类量化描述在自然语言散文中同样有效 |
| 背景绝对极淡、极简、纯氛围，禁止具象元素与文字 | 这是本元指令的创作意图核心，保留；只是"绝不能有"从负面词列表改写为正向句内约束 |
| 输入解析规则（一个内容自动补全 / 两个内容前者为主体后者为内景 / 黑白彩色可选） | 交互层规则，与模型语法无关 |
| 主体轮廓的质感约束（solid black silhouette, opaque, crisp sharp edges, no facial features, no lighting highlights on the edges） | 这些是**描述性可见约束**，不是负面词；在 qwen 中作为正向约束完全成立，且比负面列表更可靠 |
| 主体轮廓词「deep dark solid silhouette」 | 保留。原稿此处同时写 deep dark 与 solid black，属冗余，未删（不改没问题内容）；可优化为 `very dark, near-black`，但那是打磨项，不在本次格式归属改写范围 |

## 五、判定为「按 qwen 语法应当删除」的项

1. **末尾强制 `Negative Prompt: ` 字段** —— 必须删除。qwen-image 2.1 在默认 CFG=1 下负向无效；无条件输出会向下游注入无效文本。改为条件例外（true_cfg_scale > 1）。
2. **画质咒语组**（masterpiece / best quality / 8k / digital illustration style 中的画质定位） —— 必须删除。参数走接口字段。
3. **方括号 + 加号的拼接公式语法** —— 必须删除该**语法形式**；顺序作为创作方法保留。

## 六、已知不确定项

- qwen-image 2.1 的具体 `true_cfg_scale` 默认值与可调范围未在本次改写中实测，元指令按"默认 CFG=1、负向需 >1"的既有官方口径书写。若用户实际使用的部署版本默认值不同，需重新确认该条件例外是否成立。**这是待证项。**
- "彩色模式饱和度低于 3%"这类量化表述在自然语言编码器中的实际控制力未经实测，属原稿保留的意图描述，不保证数值级可控。**这是推断。**
