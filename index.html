Runtime boundary

Select it for full activation; leave it unselected and other DSH modes are unaffected.

When this mode is selected

  • A-Ji, legion rules, and PonyTail doctrine are loaded
  • `wuji_*` tools, projections, staff, and commanders are available
  • Domain adapters and verified capabilities load as needed
  • Completion requires artifacts and verification evidence

When another DSH mode is selected

  • Its own preset, plugins, and workflow remain in control
  • No legion persona, rules, or `wuji_*` tools are loaded
  • No legion memory, governance, or routing is inherited
  • Preset hot-switching is not provided

Evidence and implementation

The global architecture is documented in the global project. PonyTail principles come from the upstream repository; minimalism is grounded in YAGNI; secure-development boundaries reference NIST SSDF 1.1. Runtime claims here are limited to this repository's preset, registry, and local tests.

  • P0-P4: isolation, legion tools, task chain, memory, and evolution
  • P5: cross-domain PonyTail rules, adapters, and worker inheritance
  • Mode version: `2.0` · Host package: `0.2.0` · 16 Node tests passing

To use it, install the preset, restart DSH, create a new session, and select “Wuji Legion”.
