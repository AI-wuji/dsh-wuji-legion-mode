🔥 Three Mode Highlights
01

Explicit opt-in, no default takeover

Wuji Legion is an added mode. It does not replace minimal mode or force every conversation through legion procedures.

02

One complete contract

A-Ji, rules, task contract, scheduling, projections, memory, review, and governance activate together, avoiding competing control planes.

03

Isolated mode, bounded plugins

Installed does not mean loaded. Only base capabilities and explicitly compatible, non-conflicting shared plugins enter the mode.

🛡️ Mode Boundary
Complete activation, complete isolation.

When Wuji Legion Mode is selected

  • Load A-Ji and the complete rules
  • Enable wuji_* tools, projections, staff, and commanders
  • Enable task state, memory, governance, and compatible capabilities
  • Exclude mode-owned or conflicting control planes

When another DSH mode is selected

  • Retain that mode’s own preset, plugins, and workflow
  • Do not load legion persona, rules, or task contract
  • Do not register wuji_* tools, projections, or routes
  • Do not inherit legion memory or governance constraints
