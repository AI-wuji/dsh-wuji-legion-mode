# 地名人文艺术字元指令

## 使用说明（给调用方）

本元指令是**生成器**，不是一次性提示词。调用方把 `{地名}` 填入后交给 GPT 类 LLM，
由它按下方结构扩写出一条可直接投给 qwen-image 2.1 的提示词。

**Prompt Extend 必须关闭** `[官方]`——本元指令要求笔画内的符号位置固定可预期，
智能改写会重排文字与结构。CFG 保持默认 1；因 CFG≤1 时负向字段无效，
本元指令不使用负向词列表，所有禁项均以可见的正向约束表达 `[官方]`。

## 扩写规则（给 GPT 的固定约束）

- 只用自然语言散文，按「主体 / 构图 / 视觉风格 / 材质与光线 / 输出意图 / 约束」六段组织。
- 画面中文字**必须用引号标出**：`"{地名}"`，并写明字形与笔画呈现方式 `[官方]`。
- 不写画质咒语。`4K`、`8K`、`high quality`、`最佳质量`、`masterpiece` 一律禁止写入散文，
  它们不构成参数保证，只会干扰语义 `[官方]`。光感与质感靠材质与光线段描述。
- 不写抽象形容词。「高级感」「完美构图」「符合平面审美」必须翻译成可见结果。
- 全部笔画必须被符号占满：横、竖、撇、捺、提、钩、折七类笔画逐一说明嵌入方式，不留空笔。
- 汉字**之外**的画布区域只允许一种状态：与字面同色系的纯平底色（决定对比的载体），
  不允许任何独立实体、独立装饰、独立图案、环境、道具、投影以外的元素。
- 字数上限 250 字，不分段，一次成文，无开场语、无总结句、无解释。

## 主题锁定

本次地名：`{地名}`

需从下列方向提炼该地**真实存在**的人文历史景观特征，作为符号素材来源：
地域建筑轮廓、自然肌理、文化纹样、器物形制、文字与碑刻特征。
不得虚构该地不存在的符号。

## 三种嵌入方式（三种必须同时使用，且各自落到指定的笔画组）

1. **笔画造型替换**——用符号的整体形态重塑笔画形状。
   例：竖画外形即该地代表性建筑的正立面剪影；捺画外形即该地山形或水势走向。
2. **肌理填充**——在笔画内部铺满符号纹理，纹理随笔画走向排布。
   例：横画内填该地织物、砖石或水波的连续纹样，纹样密度随笔画粗细渐变。
3. **细节雕刻**——在笔画表面刻出符号细节，形成浅浮雕级层次。
   例：笔画转折处刻该地碑刻字体特征或木雕构件，深度克制，不破笔画外轮廓。

## 字体与画面规格

- 字形：单个方块字形的中文艺术字，笔画厚重饱满，笔画间留白通透。
- 立体表现：立体感**只能由笔画内部的层次与符号化细节产生**，是笔画自身的厚度与雕刻感；
  不靠外部投影、不靠外挂立体元素、不靠背景场景。
- 视角：正视平行投影，字形正面朝前，无透视畸变，不倾斜、不旋转。
- 投影：笔画在底色上的投影极浅且紧贴字缘，不构成独立视觉元素。
- 构图：汉字居中占满画幅主要区域，四周留窄边距，画面重心稳定。

## 输出意图

一条地名人文艺术字设计稿：汉字 `"{地名}"` 的每一笔都由该地人文历史景观符号构成，
远看是一个字，近看每一笔都是一处该地的景观或纹样。

## 约束（全部以可见结果表达）

- 画面中出现的文字只有 `"{地名}"` 这几个字，无任何其他字符、署名、水印、标注。
- 汉字占据画布中心区域，画布其余部分是单一纯平底色，其上没有独立图案或物体。
- 笔画外轮廓完整闭合，内部纹理不越出笔画边界。
- 立体层次存在于笔画表面，笔画之外是平的。
- 纯艺术字体设计：画布内容全部承载于笔画之内。
