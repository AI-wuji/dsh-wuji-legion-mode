# PonyTail Help

默认强度为 `full`，也支持 `lite`、`ultra` 和 `off`。用户明确说“停止 PonyTail”或“normal mode”时才停用。

| Skill | 用途 |
| --- | --- |
| `ponytail` | 执行最小正确行动阶梯 |
| `ponytail-review` | 审查局部过度设计 |
| `ponytail-audit` | 审查整个仓库的可删除项 |
| `ponytail-debt` | 收集明确延后的简化项 |
| `ponytail-gain` | 展示有来源的上游基准 |
| `ponytail-help` | 查看本参考卡 |

辅助 Skill 是按需调用的单次工具，不是每个简单任务的必经流程。
