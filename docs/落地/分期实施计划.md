## P1 验四层：证明四层能端到端跑通

**这是最高优先级的一期。** 理由（评审人 3 的原话，方案已引）：

> **「先证明四层能跑起来一次，再回来写它的宪法」**

**当前已知**：上一次实测中**四层退化成两层**——真实原因是**我派子代理时没让它加载主帅 skill**，不是架构缺陷（见方案 §12.1.5 的更正）。

**所以 P1 要做的，正是把这个更正变成可复现的证据。**

| # | 任务 | 完成标准 |
|---|---|---|
| 1.1 | 派一个子代理，**显式要求加载 `wuji-leader-*`** | 子代理回交内容体现主帅五要素 |
| 1.2 | 观察主帅是否真的组织成员 | 产物中能看到成员分工，而非主帅代写 |
| 1.3 | 观察参谋部是否参与 | 有 `wuji_staff_plan` 的实际输出 |
| 1.4 | 记录一次完整链路 | 阿极 → 参谋部 → 主帅 → 专家，**四层各有痕迹** |

**P1 验收标准**：一次任务的**产物 + 证据链**，能证明四层**各自实际参与**。

**诚实边界**：即使 P1 通过，也**只有 n=1**，不能断言「四层永远可靠」。
只能说「**在这一个任务上，四层按设计运转了**」。
