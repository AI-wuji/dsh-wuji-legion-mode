# 无极军团模型路由

> 当前可用模型来自 DSH settings 实际配置，不虚构 Luna/Earth 路由。

| 用户选择 | 优先级 | 说明 |
|---|---|---|
| GPT | `gpt-5.6 → gpt-5.6-terra → gpt-5.6-sol` | 阿极默认从 `gpt-5.6` 开始；前一档不可用才回退下一档 |
| DeepSeek | `deepseek-v4-flash → deepseek-v4-pro` | 普通任务优先 Flash；Flash 不可用才回退 Pro |
| 视觉 | 当前模型原生图片输入 | 当前模型支持图片则直通；不支持时由 ModLens 视觉旁路接管 |

## 路由规则

1. 用户先选择模型家族：GPT 或 DeepSeek。
2. GPT 家族严格按 `5.6 → terra → sol` 回退，不因角色擅自把 Sol 提到首位。
3. DeepSeek 家族严格按 `flash → pro` 回退。
4. 简单任务不启动参谋部慢路径。
5. 阿极不做全局分析，只收集和澄清。
6. 参谋部是唯一全局调度者；主帅只做域内选型。
7. 当前 settings 未发现 Luna/Earth 的有效 provider/model，不配置虚构名称。
8. 模型是否可用以及图片能力，以 DSH `llm.resolveModelInfo()` 实际结果为准。
