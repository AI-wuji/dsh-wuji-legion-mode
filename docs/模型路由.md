# 无极军团模型策略（4.0）

> 4.0 不再有自研模型路由。模型由宿主配置决定，军团**不自建模型表**。

## 为什么删掉了 3.0 的模型策略

3.0 用 `packages/wuji-host/lib/model-policy.js` 实现了一套推理强度策略
（继承宿主模型、普通任务 `medium`、高推理请求 `max`、生成前降级 `xhigh`、
生成后禁止切换、禁止 A/B 测试）。4.0 全部移除，原因：

1. **DSH 已有官方承接**：`dsh-agent-default-model` 决定默认 provider/model，
   preset 可通过 `config` 覆盖；模型选择在 UI 里对用户可见可改。
2. **自研策略与宿主配置会打架**：用户在 DSH 设置里选的模型，与军团内部
   偷偷改 effort 的规则冲突时，回执无法对应真实执行身份。
3. **上层的白帽要求已经覆盖它**：4.0 SKILL.md 明确「请求不等于生效，
   实际模型/档位/配额不可核验即 `unknown`；不换模或改配置来补证」。

## 4.0 的模型规则

| 维度 | 规则 |
|---|---|
| 来源 | 宿主配置（`dsh-agent-default-model` + profile patch） |
| 本模式是否覆盖 | 否。preset 不设置 `provider` / `model` |
| reasoning effort | 由用户在 UI 或 profile 配置；模型不主动切换 |
| 生成之后 | 不切换。换模型会让回执无法对应真实执行身份 |
| 不可核验时 | 如实标 `unknown`，不猜测、不靠改配置补证 |
| A/B 测试 | 禁止（除非用户明确要求且授权） |

## 与本机配置的关系

本机 `profiles/desktop/cordis.patch.yml` 里配置了多个 provider
（本地模型、`deepseek2x`、`gpt005` 等），默认是：

```yaml
- id: agent-default-model
  name: "@deepseek-ai/dsh-agent-default-model"
  config:
    provider: deepseek2x
    model: deepseek-v4.1-flash
```

这是**宿主层**配置，与无极军团 preset 无关：军团会话沿用它的结果，
不修改它，也不为某个任务临时改它。
