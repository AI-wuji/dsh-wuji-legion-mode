## 刻意不做

- 不把 `wuji-host` 写入 `profiles/desktop/cordis.patch.yml`；否则其他 preset 也会看到军团工具。
- 不将 `wuji` 设为 `agent-presets.default`；用户在新会话中自主选择。
- 不支持已开始会话热切换 preset；这是 DSH 原生约束，已开始会话的组成与工具日志必须保持一致。
- 不假定 `subagent`/`subagent_fork` 是不同权限模式：它们继承父 preset generation；需要异构审查时应使用显式 provider/preset 设计。

## 安装与验证

```powershell
.\scripts\install-local-profile.ps1
cd packages\wuji-host
npm install
npm test
dsh --profile desktop --dump-config
```

安装器已实际验证可重复运行、会生成安装备份，且 `dsh --profile desktop --dump-config` 不含 `wuji-host` 或 `default: wuji`。重启 DSH 后创建新会话，并在 preset 选择器中选择“无极军团”。`standard`、极简或其他 preset 的新会话不应出现 `wuji_*` 工具、军团 persona 或 Wuji 投影。

更完整的边界说明见 [`MODE-IMPLEMENTATION.md`](MODE-IMPLEMENTATION.md)。
