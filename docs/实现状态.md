## 当前宿主资源

- 投影：`wuji.requirement`、`wuji.task`、`wuji.officer-advice`、`wuji.memory`、`wuji.evolution`、`wuji.telemetry`
- Host 服务：`wujiStaff.validatePlan()`、`plan()`、`readyTasks()`
- 工具：`wuji_staff_plan`、`wuji_staff_dispatch`、`wuji_commander_select`、`wuji_officer_advise`、`wuji_council_plan`、`wuji_memory_write`、`wuji_evolution_propose`、`wuji_evolution_promote`、`wuji_feedback_record`、`wuji_status`
- 能力目录：11 项（飞书文档/表格/IM、HTML/PPTX 演示、开发、搜索、写作、视觉旁路、浏览器控制、ComfyUI 控制）
- 本地软件控制：优先使用 DSH 原生 shell/subprocess/terminal/MCP；ComfyUI 优先本地 HTTP API，执行时探测，不能用时明确报告，不自动启动软件
- 情报官入口：`wuji_intelligence_search`，调用 DSH 原生 `web.search`；情报官只收集，参谋部负责分析
- 客观判断：阿极内置，不再作为独立官员职权
- 模型路由：GPT 严格 `5.6 → terra → sol`；DeepSeek 严格 `flash → pro`；详见 `docs/模型路由.md`
- 默认 preset：Desktop 实际 patch 已改为 `default: wuji`，新会话默认进入阿极轻量 preset；旧会话保留原有历史和 preset，不强制迁移
- J-Space：不安装插件，仅蒸馏工作集限制、目标保持、中间桥接和自我监测，复用现有任务表/记忆/参谋部
- 图像输入：gpt-5.6 / gpt-5.6-sol / gpt-5.6-terra 已声明 `input: [text, image]`；非视觉模型可通过已审计的 ModLens 3.20.0 `modlens_read_image` 视觉旁路，但仍需配置 ModLens engine 才能真正识图
- 能力治理：能力目录已升级来源、兼容性、风险、版本回滚元数据
- 冷恢复稳定性：所有 projection schema 已做 cold-restore 回归测试；曾修复 `wuji.telemetry.task` 漏包 `z.object()` 导致的重启历史加载失败
- 已验证：Desktop 最终组合包含 `default: wuji`、ModLens、wuji-host、Playwright MCP；当前运行时已出现 `wuji_intelligence_search` 和 24 个 `mcp__playwright__*` 工具
- Desktop patch 曾被插件安装器重置为 `[]`，现已恢复，并已把自动恢复逻辑写入安装脚本
- 已验证：ComfyUI 当前在线，`/system_stats`、`/object_info`、`/queue`、`/history` 均返回 200；当前队列 running=0、pending=0，未提交真实工作流
- 未闭环：旧会话仍有最大约 580K surface / 728K pressure，需新会话对比；本机缺少 ollama/llama-server/agy/gemini engine，ModLens 仍需配置视觉引擎；本机已有 Qwen3.5 GGUF + mmproj 候选，但尚无 llama-server 服务；ComfyUI 实际工作流提交、GPT 两端点健康对比仍待完成
- 上下文策略：稳定前缀/变化后缀、Skill 渐进披露、无第二套 supervisor/记忆、工具执行前门禁；648K 上下文仍需用 tokenMeter 分项测量后再减法
- 通用 `web_search`：确认是外部工具占位 Key 失效；无极情报统一使用 DSH 原生 `wuji_intelligence_search → ctx.web.search`
